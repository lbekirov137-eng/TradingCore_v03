## 4. Реализовано

`round_price_to_tick` (режимы nearest/down/up) · `round_quantity_to_step`
(всегда ВНИЗ) · `validate_order_geometry` · явные причины отказа:
`LEVELS_COLLAPSED`, `STOP_DISTANCE_ZERO`, `TARGET_COLLAPSED`,
`QUANTITY_ZERO`, `BELOW_MIN_QUANTITY`, `BELOW_MIN_NOTIONAL`,
`RR_DISTORTED_BY_ROUNDING`.

Направления округления выбраны так, чтобы ошибка шла в безопасную сторону:
стоп — вниз (риск чуть больше заявленного, не меньше), количество — вниз
(позиция не превышает 0.1% риска).
